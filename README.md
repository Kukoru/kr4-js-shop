## Принцип безопасного вывода данных
Для вывода пользовательских данных и данных, которые в будущем могут прийти из формы, `localStorage` или API, используется `textContent`, а не `innerHTML`. `textContent` воспринимает строку как обычный текст, что защищает от XSS-атак. `innerHTML` интерпретирует строку как HTML-код, что может быть опасно.

## Повышенный уровень (Самостоятельная доработка)
Для получения максимального балла за КР №4 были реализованы дополнительные функции:
- **Корзина товаров:** добавление товаров, удаление, изменение количества (кнопки `+` и `-`);
- **Страница корзины (`cart.html`):** вывод выбранных товаров и подсчёт итоговой суммы;
- **Счётчик корзины в шапке сайта:** показывает общее количество добавленных товаров;
- **Сохранение в `localStorage`:** корзина не пропадает при перезагрузке страницы;
- **Визуальная анимация кнопки:** при добавлении товара кнопка меняет текст на «Добавлено ✓»;
- **Расширение каталога:** массив товаров увеличен до 8 позиций (требование методички).
