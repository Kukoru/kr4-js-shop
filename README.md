## Принцип безопасного вывода данных
Для вывода пользовательских данных и данных, которые в будущем могут прийти из формы, `localStorage` или API, используется `textContent`, а не `innerHTML`. `textContent` воспринимает строку как обычный текст, что защищает от XSS-атак. `innerHTML` интерпретирует строку как HTML-код, что может быть опасно.

## Практическая работа №16
Тема: «JavaScript: базовые задачи. Условные операторы, циклы, массивы и методы массивов, простые алгоритмические задачи».

Выполнено:
- один объект товара заменён на массив `products` (добавлено 6 учебных товаров с единой структурой);
- реализована функция получения названий товаров (`getProductTitles`);
- реализована фильтрация товаров в наличии (`getAvailableProducts`);
- реализован поиск по названию товара (`searchProducts` с очисткой строки через `trim()` и приведением к нижнему регистру);
- реализована фильтрация по категории (`filterProductsByCategory`);
- реализована сортировка по цене (`sortProductsByPrice` с созданием копии массива `[...products]`, чтобы не мутировать исходные данные);
- реализован поиск товара по `id` (`findProductById`);
- реализован расчёт общей стоимости товаров (`calculateTotalPrice` через `reduce`);
- реализован подсчёт товаров в наличии (`countAvailableProducts`);
- реализован расчёт средней цены (`calculateAveragePrice`);
- реализовано комбинирование поиска, фильтра и сортировки в функции `getPreparedProducts`;
- результаты работы всех функций проверены через консоль браузера (`console.log`, `console.table`);
- краткая статистика (всего товаров, в наличии, средняя цена, результаты поиска) выведена на страницу через `textContent` в блоке «Проверка JavaScript».
